# GIMP 0.2.0

## New Features

* Added GEO dataset processing functions for automated download and processing of methylation data from GEO
* Implemented `read_idat_zip()` for streamlined IDAT file processing from ZIP archives
* Added interactive Shiny application (`GIMP_app()`) for graphical analysis

## Improvements

* Enhanced documentation and examples
* Improved sample sheet handling with flexible column mapping
* Added parallel processing support for faster data processing
* Better error handling and diagnostic messages

## Bug Fixes

* Fixed detection p-value calculation issues
* Improved IDAT file matching algorithm
* Enhanced handling of missing or malformed data
